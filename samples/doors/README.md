# Door sound samples

Short recordings of door sound presets, so you can hear a preset in the panel before choosing it.

Name each file after the preset id exactly as the Doors tab shows it in the list (for example `DEFAULT_DOOR_GARAGE.ogg`
or `DEFAULT_DOOR_SWING_WOOD.wav`). `.ogg`, `.mp3` and `.wav` work; keep them short (a door opening and closing).
Custom door sound sets use their sound set name (for example `door_garage_ls_customs.ogg`).

How to record one: in game, open the panel's Doors tab, pick the preset on a door, export, reconnect, press **Test**
and record the game audio with any recorder (OBS, ShadowPlay...). Trim it and drop it here, then restart the resource.
